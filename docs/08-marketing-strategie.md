# Sphère 8 — Marketing et stratégie

## Positionnement

**Pour** les personnes qui veulent un journal **sans compte et sans cloud**.  
**Contre** Day One, Journey, Notion : eux sync / abonnement.  
**Promesse :** vos pensées ne quittent pas le téléphone.

## Canal actuel

- Site : [mespensees.vercel.app](https://mespensees.vercel.app/)
- APK : GitHub Releases (pas le Play Store).
- LinkedIn créateur : [credo-credson-adjignon](https://www.linkedin.com/in/credo-credson-adjignon/)
- Portfolio : GitHub Pages

## Messages qui marchent

- « 100 % local » (vrai, avec nuance géoloc).
- « PIN + leurre » (différenciant rare).
- « Capsules temporelles » (émotionnel).

## Messages à éviter

- « Cryptage militaire ».
- « Disponible iOS » (faux).
- Stats inventées (« 365 jours d’innovation »).

## V2 stratégie

1. **Play Store** = distribution réelle (keystore, fiche, Data safety).
2. Une **vidéo 20 s** (unlock → écrire) sur le site et LinkedIn.
3. Changelog public à chaque release (confiance = transparence).
4. Pas de pub intrusive ; le produit est la privacy.

## Pricing

Rester **gratuit** en v2. Un « soutien Moov Money » existe déjà. Un paywall casserait le discours local-first tant qu’il n’y a pas de serveur.
